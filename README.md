# UnlockingFoundatinsHackathon_Ufa2025
**Цель: За 1 сутки разработать консольное приложение игру на языке C++, посвященную поступлению в Уфимский университет науки и технологий**

**Дата: Весна 2025**

**Технологии: С++**

**Результат: Победа**

## Инструкция пользователя
В корне проекта можно найти файл с расширением .exe, запустив который начнется игра.

## Особенности
- Экономическая стратегия
- Процедурное программирование
- Воссозданная с помощью обычных символов карта университета
- Выбор факультета
- Посещение лекций и практик с дальнейшим ответом на вопросы, связанные с выбранным факультетом
